# Silicon ecosystem problems log

Problems hit while building Silicon Mode against the Silicon ecosystem (Accounts, Cells, Apps,
Interfaces, CLIs). Each entry: what happened, where it comes from, workaround used, and status of
an upstream fix (issue/PR link when filed).

| # | Area | Problem | Workaround in Silicon Mode | Upstream |
|---|------|---------|----------------------------|----------|
| 1 | Interfaces | An unverified/verified Interface must name 1–100 `app_ids` (`silicon-apps/crates/apps/src/interfaces.rs::validate`). Only `trusted` interfaces may have none, so "an interface which doesn't use any silicon app" isn't possible today. | Created a **draft** Silicon App `silicon-mode` (never published) as the Accounts OAuth client + Cells link. Interface listing can name it. | Needs a `trusted` request from a Carbon in the Developer UI. |
| 2 | Interfaces | No CLI for Interfaces; creating one needs a Carbon in developers.teamofsilicons.com. A Silicon (si:tos) can't do it. | Deferred: listing on interfaces.teamofsilicons.com is a manual step for c:shubham. | — |
| 3 | Cells auth | Cell `redirect_urls` accept only exact http(s) URLs — no custom schemes (RFC 8252 private-use schemes like `ai.tos.mode:/…`) and no loopback-any-port (Accounts allows both). Native apps need a fixed loopback port or Universal/App Links. | Mac: fixed loopback `http://127.0.0.1:47291/auth/callback`. Mobile: `https://mode.teamofsilicons.com/auth/{ios,android}` bounce pages → `ai.tos.mode://` deep link. | Loopback part fixed in silicon-cells#2; custom schemes left for discussion (token-mode returns tokens, not a PKCE code). |
| 4 | Cells | No Swift or Kotlin client for Cells (only TS + Rust). | Hand-written thin URLSession / OkHttp clients. | — |
| 5 | Silicon Apps | Store packages must be CLIs for linux/windows/macos with `--help`, `accounts --json`, `login status --json`. A GUI-only Mac app can't be published without a CLI shim. | App stays a draft; distribute a notarized DMG. | — |
| 6 | Spec | `understanding.md` points at creds `silicon-browser/target/release-tools/private/tos-silicon.json`, which doesn't exist. The Mac's CLIs are signed in as si:tos instead. | Used the signed-in CLIs. | n/a |
| 7 | Cells | When a cell is created with `--app`, it copies the app's redirect URIs, including `http://127.0.0.1/auth/callback` (no port). Accounts treats loopback as any-port, but Cells requires an exact match, so that copied entry can never work. | Replaced with `silicon-cells settings` (explicit port). | Fix PR: https://github.com/teamofsilicons/silicon-cells/pull/2 (portless loopback matches any port, RFC 8252 §7.3). |
| 8 | Cells JS client | `@teamofsilicons/cells` 0.3.0 in cookie mode only learns the session expiry from `refresh()`, so until a refresh it calls `/auth/user` before every request — each of which triggers an Accounts introspection server-side. | Web app calls `cell.refresh()` once at load (`web/lib/cell.ts`). | To file: set the cookie expiry from `/auth/user`, or return it there. |
| 9 | Vercel | `vercel domains add mode.teamofsilicons.com` / `vercel alias set` fail with `domain_not_owned` because the teamofsilicons.com apex isn't in the team. | Project-domains API (`POST /v10/projects/{id}/domains`) + `_vercel` TXT challenge + `/verify` (`web/scripts/vercel-domain.py`). | n/a |
| 10 | Namecheap CLI | `namecheap-cli` setHosts sends no `EmailType` and drops `IsActive`/DDNS flags, so `dns add` can wipe the `@ MX` record on teamofsilicons.com. | `web/scripts/namecheap-zone.py`: snapshot, compare-and-set keeping EmailType, diff, restore. | To file upstream (helgesverre/namecheap-cli). |
| 11 | Next.js 16.4.6 | Turbopack persistent build cache panics ("ModuleGraph::from_graphs_inner was canceled") on the second build. | Disabled `turbopackFileSystemCacheForBuild` in `web/next.config.ts`. | To file. |
| 12 | Cells realtime/events | Every row change is captured into tenant `_cells.events`, marked relayed but never deleted (`main@41a5691`), so churn grows `database_bytes` without bound. | Coalesced pushes, small rows, prune job. | Fix PR: https://github.com/teamofsilicons/silicon-cells/pull/4 (compile-checked; integration suite still to run). |
| 13 | Cells auth | Accounts introspection runs on every authenticated REST call and every 250 ms per open realtime socket, uncached. | Mac opens its socket only while Silicon Mode is active or questions are pending. | Candidate PR: short-TTL introspection cache. |
| 14 | Cells docs | RPCs need an explicit `GRANT EXECUTE … TO cla_<hex>`; only visible in integration tests, not user docs. | Migration grants via a DO block. | Docs PR: https://github.com/teamofsilicons/silicon-cells/pull/3 |
